## 源代码（Python）

行内代码示例：使用 `print()` 函数输出内容。

```python
def fibonacci(n):
    """计算斐波那契数列前 n 项"""
    if n <= 0:
        return []
    elif n == 1:
        return [0]

    fib = [0, 1]
    for i in range(2, n):
        fib.append(fib[i-1] + fib[i-2])
    return fib

# 主程序
if __name__ == "__main__":
    n = 10
    result = fibonacci(n)
    print(f"斐波那契数列前 {n} 项: {result}")
```
